Two ways to use XRatio

Choose the workflow that matches your session.

Client→XRatio→Tracker

Change the announce, keep your client.

Point your torrent client to XRatio’s local HTTP/HTTPS proxy. Set reporting rules, then compare the original and reported upload and download counters.

↳Your client still handles files and peer-to-peer traffic.
.torrent→XRatio→Tracker

Send announces independently.

Load a .torrent file, select a client profile and configure speeds, progress and counters. Start and stop the simulation from XRatio, without running a separate torrent client.

↳Simulation sends tracker announces. It does not transfer files.
