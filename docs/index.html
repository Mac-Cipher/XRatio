GOOD TO KNOW

A few details, before you start.

Does XRatio download torrent files?

No. Interception works with your existing client. Simulation sends tracker announces without transferring actual files.

Do I need to install .NET?

No. The published Windows executable is self-contained.

How does HTTPS interception work?

HTTPS interception uses a local certificate authority. Trust requires an explicit action in the app’s Platform view. Follow the integrated guide for setup.
