LES GARDE-FOUS

Local par défaut. Explicite par choix.

01

Le proxy reste local

Il écoute par défaut sur 127.0.0.1:3773 et ne traite ni les payloads ni le trafic pair-à-pair.

02

HTTPS demande votre accord

La CA locale n’est ajoutée à Windows qu’après une confirmation claire, pour l’utilisateur courant.

03

La simulation garde TLS strict

Les sessions directes conservent la validation TLS du système au lieu de contourner les certificats.
